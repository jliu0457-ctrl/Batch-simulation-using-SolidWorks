## 1. 七变量与真实 CAD 参数

外部 Dmax 与 cone_base_d 是同一个参数的别名，统一进入 Dmax_mm，不增加设计自由度。实体口径固定为：蝶板在关闭时流道法平面上的投影最大卡尺直径。在本模板中使用蝶板局部 yz 平面测量，并在关闭装配状态确认其方向与流道法平面一致。

输入长度用 mm、角度用 °，写入 CAD API 前换为 m、rad。下表零件简称对应同编号、同名称的 .SLDPRT 文件，JSON 配置保存完整文件名。

|---|---|---:|---|

| e_mm | 径向偏心距：阀杆轴线与流道轴线之间的偏置 | 3.7 | 03阀体：D30@草图4<br>03阀体：D4@草图6<br>09密封圈：D9@草图1<br>11蝶板：D1@草图1<br>11蝶板：D1@基准面2 |
| phi_deg | 偏心角 | 8.25 | 03阀体：D3@草图5<br>08大垫片：D5@草图1<br>09密封圈：D5@草图1<br>10压板：D4@草图1<br>11蝶板：D2@草图3 |

`Dmax_mm`仅是蝶板最大投影直径，不是公称通径。阀体流道、入口/出口管道和封盖尺寸不随Dmax缩放。开度固定45°，不在七变量内。

### 蝶板盘板轴向随动（2026-09-19 新增，必须保留）

**`c_mm` 在蝶板上要写两个尺寸，不是一个：**

```text
11蝶板：D2@草图1 = c_mm          # 定位密封锥面
11蝶板：D6@草图1 = c_mm + 12     # 定位盘板整组（本次新增）
```

**为什么必须加第二条。** 蝶板 `草图1` 里 `D2@草图1` 是**独立**定位密封锥面的；盘板那一组面的轴向基准是 `D6@草图1`，而 `D4`/`D5` 只是相对 `D6` 的偏移。`D2` 不在 `D6` 这条链上 —— 只写 `D2` 时，`c` 一变**锥面走了、盘板整组留在原地**，零件被剪切。

后果是一条链：盘板不动 → 大垫片被它与蝶板的配合拽住、动不了 → 大垫片和已经走掉的密封圈错开约 1mm → 三个环件互相穿插。实测（全量七变量，`c=31`）环件干涉合计 **`9514.03 mm³`**，其中 `09密封圈+08大垫片 8350.31`、`09密封圈+11蝶板 1018.10`。

**为什么是 `+12`。** `D6@草图1` 是**蝶板最远的那个底面到阀杆中心**的距离。母版上 `D6 = 44`、`c = 32`，差值 12。要求是盘板与锥面**刚性同步**（厚度 `D7 = 55` 不变），即 `ΔD6 = Δc`，所以写成 `c + 12`。

**母版文件本身不需要改。** `c` 的基准值是 32，`32 + 12 = 44` 正是母版里已存的 `D6@草图1` 值，所以 `config/cad_template_manifest_v6.json` 的哈希保持有效，模板无需重新定版。

**修复前后的实测**（同一组设计：`c=31, e=4, phi=8.5, alpha=34.5, Dmax=189, bm=7.2, ds=44`）：

| 零件对 | 修复前 | 修复后 |
|---|---:|---:|
| 09密封圈 + 08大垫片 | `8350.31` | **`0`** |
| 09密封圈 + 11蝶板 | `1018.10` | **`0`** |
| 03阀体 + 09密封圈 | `143.02` | `250.74` → **`0`**（2026-09-20 修掉，见下节） |
| 03阀体 + 10压板 | `2.60` | `4.30`（母版固有 `1.09`，非本次引入） |

蝶板相关的环件干涉全部清零。`s` 反解仍为 **3 轮**，未影响已验证的耗时路径。

**更正（2026-09-20）**：上一版这里曾把 `阀体+密封圈 250.74` 写成"装配缝隙量级、不是形状干涉"——**那是错的** ✗。它是真实的形状干涉，根因和修法见下一节。只有 `阀体+压板 4.30` 里的母版部分（`1.09`）才是固有量级。

**注意：不要动 `11蝶板：D1@草图2`。** 它是**以阀杆为中心的那个凸台的半径**（母版 34，Ø68），不是"+x 端的位置"。把它当成端面位置去补偿会同时把凸台撑成 Ø70 —— 实测那样做干涉同样是 0、包围盒厚度看着也"守恒"，但凸台已经偏离设计，且体积变化里混进了这一项，不能拿来当验收依据。用包围盒跨度（`D6 + D1@草图2`）判断厚度也是错的：那只是两个尺寸相加，蝶板的真实厚度是 `D7 = 55`。

### 密封圈锥面随 s 移动（2026-09-20 新增，必须保留）

**`09密封圈` 的母线在 `194.37` 构造线终点处被打断成两段，新顶点与构造线终点重合。**

**`194.37` 就是 `s`。** 五个零件的 `194.37` 挂的是同一条构造线：从 `(−32, −92.9393)` 出发、方向**垂直于倾斜线**（倾斜线与水平成 `φ`，所以这条构造线与竖直成 `φ`），长度 `s`，终点落在 `(−4.1093, 99.4193)`。适配器写 `03阀体：D5@草图5`、`08大垫片：D6@草图1`、`09密封圈：D7@草图1`、`10压板：D5@草图1`、`11蝶板：D3@草图3`，写的就是这条构造线的长度。

**阀体能动、密封圈不能动，差别只在母线怎么画：**

```text
03阀体 / 11蝶板 / 08大垫片 / 10压板：母线【从构造线终点起画】，那里是母线的一个顶点
09密封圈                          ：母线是一整条，构造线终点只是"落在母线上"
```

**后果有两层：**

**① 母线不动。** "点在线上"的点可以沿母线自由滑动，改 `s` 时它滑走、母线纹丝不动——这就是"改 `194.37` 梯形完全不变"的原因。

**② 就算把点焊上去，增量也会大一倍。** 母线是整条时，求解器用"整条母线沿自身平移"吸收 `Δs`，锥面走满 `100%`；打断成两段、出现真顶点后，顶点不能再沿母线滑动，增量被迫由**构造线两端平摊**（起点沿竖中心线滑动），锥面只走 `≈48%`。

**实测（`s` 改 `−2.88`，即审核设计 `Dmax=189`）：**

| | 母线法向位移 | 占 `Δs/2` | 构造线起点 |
|---|---:|---:|---|
| 03阀体（参照） | `−1.371` | 95.2% | 沿竖中心线滑动 |
| 09密封圈（修复前） | `−2.743` | 190% | **不动** ✗ |
| 09密封圈（修复后） | `−1.337` | 92.8% | 沿竖中心线滑动 ✓ |

**干涉结果**（同一组审核设计 `c=31, e=4, phi=8.5, alpha=34.5, Dmax=189, bm=7.2, ds=44`）：

| 零件对 | 修复前 | 修复后 |
|---|---:|---:|
| 03阀体 + 09密封圈 | `250.74`（`125.37×2`） | **`0`** |

**改完几何逐位不变**：`vol 89696.263 → 89696.263`，包围盒、锥面 `R105.2048 ha17.75 area4648.23` 全部相同；草图点数 `14 → 15`（多出的就是打断产生的那个顶点）。母线两个端点的位移向量完全相同 → 整体平移、**不旋转**，锥角不变。

**实现要点（`SplitOpenSegment` 的坑）**：这个 API 只作用于**被选中的**开放线段——不选中直接调用是**静默 no-op** ✗。必须先用两端点坐标定位母线、`Select4` 选中再调用；打断后 P2 处会出现**两个重合的点**（`points_at_p2 = 2`），那才是要焊接的一对。先前证伪的路线（只加 `sgCOINCIDENT`、先平移再加、先钉高度再加、删母线重画）都已试过，**只有 split + 重合这一条成立**。

### 压板锥面随 s 移动 + 矩形外沿随 s（2026-09-20 新增，必须保留）

**压板和密封圈是【同一类病、不同接法】，所以不能照搬密封圈的改法** ✗。`10压板 草图1` 里做了两处改动：

```text
① D8 / D12 基准对调（防的是"锥面不跟 s"）
     改前:  D8  = 95.61  ← 驱动   锚点(-4.335,97.861) ←→ 固定点(-18.0547, 3.24)
            D12 = 1.575  ← 从动
     改后:  D8  = 1.575  ← 驱动   锚点 ←→ 194.37构造线的【终点】(-4.109, 99.419)
            D12 = 95.61  ← 从动

② D13 矩形外沿随 s（防的是"锥面跑出材料"）
     D13@草图1 = (s/2 + 13) − 47.5        # 矩形径向跨度；47.5 是矩形内沿
```

**为什么①必须做。** 压板的母线**不穿过**构造线终点 ✗（这点和密封圈不同 ✗），它的位置由一个锚点 `(-4.335, 97.861)` 决定 —— 锚点既在构造线上、又在母线上 ✓。但原来那个 `D8 = 95.61` 把锚点**拴在一个不动的点上** ✗（`(-18.0547, 3.24)` 是两条固定构造线的交点 ✗）。于是：

```text
194.37 变长 → 构造线几乎只【沿自身滑动】
            → 起点沿线滑 +1.410、终点沿线移 −1.470，垂直方向只挪 0.2045
            → 锚点只继承垂直分量 0.207 ✗ → 母线横移 0.2 ✗ → 锥面不动 ✗
```

**改成量到构造线终点之后** ✓，锚点被终点拖着走 ✓ —— **实测**：

| | 母线两端位移 | 法向 | 构造线起点 |
|---|---|---:|---|
| 03阀体（参照） | 相同 | `−1.371` | 沿竖中心线滑动 |
| 09密封圈（已修） | 相同 | `−1.337` | 沿竖中心线滑动 ✓ |
| **10压板（本次修复后）** | **相同** ✓ | **`−1.339`** ✓ | 沿竖中心线滑动 ✓ |

**三者的法向位移落在 −1.337 ~ −1.371 之间** ✓ —— 即"锥面随 `s` 走约 `Δs/2`" ✓，互相一致 ✓。

**改完形状不变** ✓：`vol 224076.89 → 224076.89`、包围盒、锥面全同 ✓（母线两端位移向量完全相同 → 整体平移、无旋转 ✓，锥角不变 ✓）。

**为什么②必须做。** 压板毛坯矩形的**外沿整个落在旋转切除区内、会被切掉，不是成品表面** ✗ —— 和密封圈一样 ✓。实测把 `D13` 放 **+10mm**：`vol 224076.89`、包围盒、两个锥面**分毫不变** ✓✓✓。所以让外沿随 `s` 外扩是**零成本**的 ✓，而且能防止 `s` 变大时锥面跑出毛坯 ✗。

⚠️ **压板的余量比密封圈紧** ✗（约 7.4mm vs 11.0mm ✗），所以这条式子对压板比对密封圈更有必要 ✓。

**⚠️ 适配器必须【拿掉】`10压板 D8@草图1 = s/2−1.575` 这条写入** ✗ —— 因为 `D8` 现在是**常数 1.575** ✗，再往里写 ~95.6 会**把草图写崩** ✗。压板现在和密封圈一样，从构造线继承 `s` ✓。

**⚠️ 这处修复【没有】消掉 `03阀体 + 10压板` 的 `4.30 mm³`** ✗ —— 两个假设都被实测否掉了 ✓：修好母线跟踪后它没变 ✗，加宽矩形外沿后它也没变 ✗。**说明那条干涉另有来源** ✗，见交接文档 §6.5.8。

### s 的几何范围闸门（2026-09-20 新增）

`s` 决定锥面半径（`半径 ≈ s/2`，实测 `d半径/ds = 0.4948`，母版锥面 `97.185 = 194.37/2`），而 `09密封圈` 的材料径向只有 **`70.0 ~ 108.1723`**，所以 `s` 超出约 **`140 ~ 216.34`** 时锥面就跑出材料：

| s | 体积 | 现象 |
|---:|---:|---|
| `138` | `1960131` | 崩掉，锥角 `17.75° → 9.50°` |
| `150` | `6821` | 几乎被切光 |
| `194.37`（母版） | `89696` | 正常 |

**闸门最终定为 `145 ~ 200`**（`SevenVariableAdapter.SetConstruction`）：

- **下限 145 由 `09密封圈` 的 Ø140 内孔决定** —— 锥面半径 `s/2` 低于 70 就顶进孔里，`s=138` 实测直接崩（体积 `89696 → 1960131`、锥角 `17.75°→9.50°`）。
- **上限 200 由 `03阀体` 决定，不是密封圈** ✗。扫出来的坎很陡：

| Dmax | 解出 s | 结果 |
|---:|---:|---|
| 189 | 191.49 | ✓ |
| 193 | 196.59 | ✓ |
| 196 | 200.44 | ✓ |
| 197 | ≈201.4 | ✗ `03阀体 feature_errors=[{"name":"分割线1"}]` |
| 203 | ≈207.5 | ✗ 同上 |

**曾一度把上限写成 212（由密封圈外圆边推算）——那是错的** ✗：200.5~212 之间的样本会跑失败。**真实上限由阀体的分割线特征决定** ✓。

实测双向生效：范围内 `s=191.49` → `completed=true`；范围外 `s=72.21` → `completed=false` 并报错，**不产出坏样本**。

⚠️ **下限由密封圈导出、上限由阀体导出，另外四个零件（蝶板、垫片、压板、阀轴）各自的边界还没扫**，所以闸门仍是**必要但不充分**的。压板和密封圈的毛坯外沿已随 `s` 外扩（见上文两节），所以它们**不再是**上限的来源 ✓。

**矩形的两条边性质完全不同，别一概而论（2026-09-20 更正）：**

```text
矩形【外圆边】(108.1723)  →  整个落在切除梯形内部 → 被切掉 → 【不是成品表面】
                             放大它不影响成品 ✓（实测 s 从 194 扫到 215，体积始终线性、无拐点）
矩形【内孔边】(70)        →  切除区够不到它     → 是真实的孔 Ø140 → 【不能动】✗
```

这块环件的**成品外表面就是那个锥面**（密封圈的外锥面坐在阀体锥座里）。所以放宽 `s` 上限的**根本办法是把矩形外圆边加大**，而不是加闸门：

```text
09密封圈：D10@草图1 = (s/2 + 12) − 70    # = s/2 − 58，矩形径向跨度；外圆边保证包住锥面
```

**已落地** ✓：`D10@草图1` 是矩形的径向跨度（外圆边 `−` Ø140 内孔半径 `70`）。适配器里是 `SevenVariableAdapter.SetConstruction` 的 `derived_ring_outer_edge`，常量 `RingOuterMarginMm = 12`、`RingBoreRadiusMm = 70`。**回归验证**：审核设计 `s=191.49` 仍 `completed=true` ✓。

⚠️ **内孔边 `70`（Ø140）绝对不要动** —— 那是真实的流道孔。

## 2. 实体 Dmax 的独立控制

CAD 的 194.37 mm 是内部锥面构造基圆直径 s，不是蝶板实体最大外径，也不是额外的优化变量。适配器先写入其余六个设计变量，再根据实体测量反解 s，并联动以下尺寸。

| 零件 | 内部构造参数 | 写入值（mm） |
|---|---|---|
| 03阀体 | D5@草图5 | s |
| 08大垫片 | D6@草图1 | s |
| 09密封圈 | D7@草图1 | s |
| 10压板 | D5@草图1 | s |
| 11蝶板 | D3@草图3 | s |

| 零件 | 派生参数 | 写入值（mm） |
|---|---|---|
| 11蝶板 | D5@草图3 | s/2−Δ |
| 10压板 | D8@草图1 | s/2−Δ |
| 08大垫片 | D8@草图1 | s−2Δ |

其中 Δ=1.575 mm 为现有模板固定的构造径向差：r=s/2−Δ，大垫片派生直径=s−2Δ。Δ 不表示法向间隙，也不增加为优化变量。

任何一个其他设计变量变化后，都重新求解 s，使目标 Dmax 保持不变。改变 Dmax 自身时也通过相同反解执行。求解采用区间搜索和带保护的割线/二分迭代；每次改 s 后重建实体，随后保存、重开并复测。没有达标时报告失败，不接受最后一次未收敛的尺寸。

## 3. 自适应卡尺上下界与基准

算法从 [0,π) 上的 16 个方向开始，用实体 GetExtremePoint 求各方向宽度 w。对相邻角区间 [a_i,b_i] 计算：

L=max 已采样宽度；
B_i=max(w(a_i),w(b_i))/cos((b_i−a_i)/2)；
U=max(L,max_i B_i)+10⁻¹²max(1,L)。

每次二分 B_i 最大的区间，直到 U−L≤0.001 mm；方向预算为 8192。直径验收同时要求整个 [L,U] 位于目标 Dmax±0.001 mm。该界不要求宽度函数光滑或单峰；step_deg 是最大剩余区间跨度，不是均匀步长。算术补偿不代表 CAD 内核的支撑精度，不使用近似包围盒替代实体尺寸。

当前正式基准来自 [完整 15 组报告](artifacts/seven_variable_mapping_full_geometry_v1.json) 的自适应模板测量：

| 测量项 | 结果 |
|---|---:|
| Dmax 下界 | 191.317413895593 mm |
| Dmax 上界 | 191.318314276203 mm |
| 基准 Dmax（区间中点） | 191.317864085898 mm |
| 区间宽度 | 0.000900380610 mm |
| 查询方向 / 支撑调用 | 58 / 116 |

[基准输入 JSON](config/design_baseline.json) 使用这一正式基准。早期 [smoke 测量记录](artifacts/seven_variable_mapping_baseline_smoke_v1.json) 作为历史证据保留，不再作为默认输入。

当前 v2.1 源码已通过 [30 项数学验证](artifacts/caliper_selftest_v2_1.json)，涵盖 7 个圆/椭圆与 23 个点集凸包案例。解析或点对距离真值均被上下界覆盖（比较容差 10⁻⁸ mm），区间宽度均不超过 0.001 mm。该验证不调用 SolidWorks。

### v5历史结论与v6当前方案（2026-09-17）

- v5 模板的原样副本可通过 Flow 特征重建，说明模板本身封闭。
- 旧`RepairAssembly.cs`新增阀轴/阀体同心配合并把约`2.832 mm`偏移归零。成功Flow模型证明该非零偏移允许存在；偏心蝶阀不得以“轴线归零”作为参数化门禁。
- 用户人工对照证明：V5参数化核心模型删除旧封盖并手工重建封盖后可以求解，因此V5失封来自封盖/封闭边界处理，不是六个核心零件的七变量映射。
- v6只写入六个核心零件；封盖1～4不打开、不写尺寸、不保存。开度固定45°且只读验证，不再写入角度。
- v6采用两阶段文档生命周期：保存核心零件并关闭全部文档，再重新打开装配体执行最终配合、几何和封盖验证；首次会话中的瞬态配合状态不作为最终判据。
- `fourcap_v6_changed_011`的适配器结果已达到`completed=true`、`physical_mapping_verified=true`：Dmax实测`189.000000002 mm`、45°保持、装配特征错误为空、四封盖验证通过。外层曾因把四个`~$`锁文件计入哈希而误判，哈希枚举现已排除锁文件。
- 在解决上述配合问题前，`geometry_verified` 不等于 Flow 可求解，不得生成训练行。

### 母版必需的装配配合（2026-09-19 起）

**母版 `working/assembly_batch_v7` 的装配体现在带两个强制的配合策略，缺一不可，复制模板时一并带走：**

**① 四个锁定配合必须抑制：`锁定1`、`锁定2`、`锁定3`、`锁定4`。**

锁定（`MateLock`）只冻结两个零件的**相对位置**，挡不住驱动尺寸改变零件的**形状**。`c_mm` 会改写三个环件的内部尺寸，形状变了位置没变，于是互相穿插。`锁定4`（蝶板↔阀轴）另外还会让装配体过定义。

**② 必须存在 `同心54`（11蝶板 ↔ 04阀轴）。**

`04阀轴` 在装配体里**只出现在 `锁定4` 里**，没有别的配合。所以抑制 `锁定4` 之后阀轴变成完全无约束的浮动件：`e_mm` 把蝶板孔挪了 `0.300 mm` 而阀轴不动，两轴轴线正好差 `Δe`，实测 `蝶板+阀轴` 干涉 `1643.14 mm³`。

加上这个同心配合后实测：

| | 加之前 | 加之后 |
|---|---|---|
| 两轴轴线偏移 | `0.300000 mm` | `0.000000 mm` |
| 11蝶板 + 04阀轴 干涉 | `1643.14 mm³` | **`0`** |
| 核心件干涉总量 | `13880.36 mm³` | `12237.22 mm³` |

**建配合的顺序不能颠倒**：必须先抑制 `锁定4`，再调 `AddMate5`；否则返回 **`swAddMateError_OverDefinedAssembly`（码 5）**，配合建了也带错误、轴线纹丝不动。抑制之后同一调用返回 **`swAddMateError_NoError`（码 1）**。

**选面规则**（按零件坐标系的几何特征找，不依赖面名）：阀轴工作段 = 轴沿 X、半径 15~30mm 中面积最大的圆柱面（`ds=44` 时 r=22）；蝶板孔 = 轴沿 Z、半径与阀轴工作段相差 1.5mm 以内的最大面积圆柱面。

**工具**：`scripts/Add-ShaftDiscConcentric.ps1`（`-Apply` 建、`-Save` 落盘）。`scripts/Suppress-LockMates.ps1`（`-Apply` 抑制、`-Save` 落盘）。

**注意**：这一条与上面 v5 那条「不得盲目新增同心配合」并不冲突。被否决的是**阀轴↔阀体**同心（那一对本来就该有 `2.832 mm` 的径向偏心，归零是错的）；这里是**阀轴↔蝶板孔**同心，三偏心蝶阀里阀杆与蝶板孔本来就应当同轴。

## 6. 适用范围

当前适配器要求 c、e 非负，φ>0，0<α<180°，φ+α/2<90°，且正的密封片厚度和阀杆直径均小于 Dmax。**此外内部解出的 `s` 必须落在 `145 ~ 200 mm`**（下限由密封圈 Ø140 内孔定、上限由阀体分割线定，均为实测），超出范围直接报错、不产出样本——推导见上文「s 的几何范围闸门」。这是模板入口的适用条件，不替代完整优化边界。

⚠️ 边界来自**密封圈（下限）和阀体（上限）**，另外四个零件（蝶板、垫片、压板、阀轴）各自的几何边界尚未扫描；现阶段该闸门是**必要但不充分**的。

v6当前已验证一个变化设计的CAD参数化；不表示整个优化域都可重建。Flow求解与训练行发布仍需在恢复四封盖并通过内部域重建后单独验收，当前`training_ready=false`。
